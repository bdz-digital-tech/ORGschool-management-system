. Criar Utilizador com Escola (já tem criados a cima)
Painel Admin → "Utilizadores" → "Novo Utilizador"
Preenche: Nome, Email, Senha

Perfil: Administrador de Escola
        Seleciona a escola no dropdown
        Clica "Criar"

        Utilizador criado com escolaId correto


2. Login com Isolamento Logout
Login com o utilizador criado
    Vê apenas os dados da sua escola (vazio se nova)
    Cria alunos → Aparecem só na lista dele

Logout → Login com outra escola
    NÃO vê os alunos da primeira escola

3. Configuração de Recibo por Escola
Painel Admin → "Configuração de Recibo"
    Seleciona "Escola A" → Altera nome → Guarda
    Seleciona "Escola B" → Altera nome → Guarda
    Cada escola tem o seu recibo personalizado
